Verifying a Download

Compare the SHA-256 checksum listed above with the checksum of the file you downloaded: 

sha256sum <file>.phar

The .asc file that accompanies each PHAR file is a detached OpenPGP signature. After importing the signing key, verify the signature like this: 

gpg --verify <file>.phar.asc <file>.phar

An SBOM is signed the same way: 

gpg --verify <file>.phar.cdx.xml.asc <file>.phar.cdx.xml
